# Подключение навыков к Work и Codex

Проверено по документации OpenAI 22.10.2026. Эти 10 навыков — инструкции в формате SKILL.md, **не** подключённые внешние приложения, не работающие фоновые службы и не подтверждённые интеграции.

## Что проверено

- Все десять файлов существуют в ветке и имеют YAML front matter с полями `name` и `description`.
- Навыки не содержат исполняемых скриптов, зависимостей, API-ключей или действий по умолчанию.
- Формат папка + SKILL.md соответствует концепции Agent Skills, но этого недостаточно для подтверждения установки.

## Codex

1. В поддерживаемом интерфейсе Codex проверь Sources → Use plugins и доступность установленных плагинов.
2. Для самостоятельных навыков используй поддерживаемый механизм создания/установки Skills в конкретной среде Codex; не считай файлы GitHub автоматически установленными.
3. Начни с `codex/tests` и `codex/actions` на тестовом репозитории; проверь, что навык действительно вызывается и выполняет тест, а не только пишет план.
4. Перед production-деплоем обязательно проверяй права, резервную копию, health check и план отката.

## ChatGPT Work

1. Открой Plugins и проверь доступность Skills/Plugin Creator для своего аккаунта и рабочей среды.
2. При доступности создай skill или plugin с соответствующими инструкциями; подключи только нужные приложения с минимальными правами.
3. Проверь `work/verification` на безопасной задаче: действие → наблюдаемый результат → подтверждение.
4. Наличие файла в GitHub не даёт Work доступа к браузеру, файлам или приложениям автоматически.

## Приёмочные проверки

- Навык обнаруживается и вызывается по подходящей задаче.
- При отсутствии доступа честно сообщает ограничение.
- Для операций с внешними сервисами подтверждает результат, а не только попытку.
- Не раскрывает секреты и не выполняет необратимые действия без разрешения.
- На негативном тесте (ошибка API/нет доступа) корректно останавливается и сообщает причину.
