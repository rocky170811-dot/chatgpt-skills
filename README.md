## Использование

При работе над задачей выбрать подходящий навык, прочитать его `SKILL.md` и применять инструкции. Для комплексных задач допускается сочетать навыки.

**Важно:** размещение файлов в GitHub не устанавливает их автоматически в системные навыки ChatGPT или Codex. Для конкретной среды требуется отдельное подключение или загрузка навыков.

Никогда не коммитить токены, пароли и файлы `.env`.
