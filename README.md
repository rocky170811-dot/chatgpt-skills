## Специализация сред

- **ChatGPT:** консультации, анализ, подготовка документов, координация навыков.
- **Work:** многошаговые исследования, работа с подключёнными сервисами, документами и сайтами с проверкой результата.
- **Codex:** программирование, тестирование, ревью, CI/CD, диагностика и безопасный деплой.

Скилл в репозитории не означает автоматического подключения к любой среде. Для каждой среды отдельно проверять поддержку формата, доступные инструменты и разрешения.

## Кандидаты для усиления Work и Codex

**Work:** deep research, browser workflows, spreadsheets, competitor analysis, project reporting, source verification.

**Codex:** code review, test generation, security audit, GitHub Actions diagnostics, deployment verification, rollback planning.

Кандидатов из сторонних репозиториев изучать перед включением: лицензия, безопасность, зависимости, актуальность, воспроизводимый тест.

## Использование

Выбрать подходящий навык, прочитать его `SKILL.md` и применять инструкции. При комплексных задачах сочетать навыки. Не удалять данные и не коммитить токены, пароли и `.env`.
