# Нейромонтажёр

Превращает длинное горизонтальное видео (подкаст, вебинар, интервью, ролик с YouTube) в короткие вертикальные клипы с субтитрами.

Работает по принципу: **ИИ не генерирует видео, а сжимает уже снятое**. Ты сняли — агент находит лучшее и режет.

## Что нужно один раз поставить

Проверь и поставь, если чего-то нет:

```bash
# ffmpeg — режет и собирает видео
ffmpeg -version || brew install ffmpeg          # macOS
# ffmpeg -version || sudo apt install ffmpeg    # Linux

# whisper — распознаёт речь
pip install -U openai-whisper

# yt-dlp — если исходник это ссылка на YouTube
pip install -U yt-dlp
```

Если пользователь на Windows без brew — предложи скачать ffmpeg с ffmpeg.org и добавить в PATH.

## Порядок работы

Никогда не начинай резать сразу. Сначала транскрипт → выбор кусков → **показать пользователю** → только потом рендер.

### Шаг 1. Получить исходник

Если дали ссылку на YouTube:
```bash
yt-dlp -f "bv*[height<=1080]+ba/b" -o "source.%(ext)s" "ССЫЛКА"
```

Если дали локальный файл — работай с ним напрямую.

### Шаг 2. Транскрипт с таймкодами

```bash
# Вытащить аудио (быстрее, чем гонять видео через whisper)
ffmpeg -i source.mp4 -vn -acodec pcm_s16le -ar 16000 -ac 1 audio.wav

# Распознать. base — быстро, medium — точнее, small — компромисс
whisper audio.wav --model small --language ru --output_format srt --output_dir .
```

Получится `audio.srt` — текст с таймкодами. Прочитай его.

### Шаг 3. Найти сильные куски

Прочитай транскрипт и выбери 3–5 фрагментов по 30–60 секунд. Хороший фрагмент:

- **Самодостаточный** — понятен без контекста всего видео
- **Начинается с крючка** — вопрос, спорное утверждение, обещание, цифра
- **Одна мысль** — не пытайся впихнуть три темы в минуту
- **Есть завершение** — не обрывается на полуслове

Плохой фрагмент: середина рассуждения, «как я уже говорил», перечисление без вывода, долгий заход.

Покажи пользователю таблицу и дождись выбора:

| # | Таймкод | О чём | Первая фраза (крючок) |
|---|---------|-------|----------------------|
| 1 | 12:30–13:15 | ... | «...» |

**Не рендери, пока пользователь не выбрал.** Он знает свой контент лучше.

### Шаг 4. Вырезать фрагмент

```bash
ffmpeg -i source.mp4 -ss 00:12:30 -to 00:13:15 -c copy clip_01.mp4
```

Если на границе видно подтормаживание — перекодируй вместо `-c copy`:
```bash
ffmpeg -i source.mp4 -ss 00:12:30 -to 00:13:15 -c:v libx264 -crf 18 -c:a aac clip_01.mp4
```

### Шаг 5. Убрать паузы (по желанию)

Найти тишину:
```bash
ffmpeg -i clip_01.mp4 -af silencedetect=noise=-30dB:d=0.6 -f null - 2>&1 | grep silence
```

Режь **умеренно**. Если вырезать каждый вдох — речь звучит как пулемёт и зритель устаёт. Убирай только паузы длиннее ~0.8 секунды и явные «эээ». Лучше недорезать, чем перерезать.

### Шаг 6. Собрать вертикалку 9:16

Рабочий приём: весь горизонтальный кадр целиком по центру, сверху и снизу — размытый фон из него же. Ничего не обрезается, лица не улетают.

```bash
ffmpeg -i clip_01.mp4 -filter_complex \
"[0:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,gblur=sigma=20[bg]; \
 [0:v]scale=1080:-2[fg]; \
 [bg][fg]overlay=(W-w)/2:(H-h)/2" \
-c:v libx264 -crf 20 -c:a aac -r 30 vertical_01.mp4
```

Не используй жёсткий центр-кроп (`crop=ih*9/16:ih`) — если человек в кадре сместился, ему отрежет голову.

### Шаг 7. Субтитры

Распознай именно клип (таймкоды должны совпадать с ним, а не с исходником):

```bash
whisper vertical_01.mp4 --model small --language ru --output_format srt --output_dir .
```

Вжечь в видео:
```bash
ffmpeg -i vertical_01.mp4 -vf "subtitles=vertical_01.srt:force_style='FontName=Arial,Fontsize=16,Bold=1,PrimaryColour=&H00FFFFFF,OutlineColour=&H00000000,Outline=3,Alignment=2,MarginV=120'" -c:a copy final_01.mp4
```

Параметры под себя:
- `Fontsize=16` — размер (для 1080×1920 обычно 14–20)
- `MarginV=120` — отступ снизу, чтобы текст не попал под интерфейс TikTok/Shorts
- `Alignment=2` — по центру снизу

Перед вжиганием **прочитай .srt и почини ошибки распознавания** — имена, термины, названия. Whisper часто перевирает их.

## Что показать в конце

- Путь к готовым файлам
- Длительность каждого клипа
- Текст крючка (первая фраза) — пригодится для подписи к посту

## Частые грабли

- **Клип длиннее 60 сек** — Shorts обрежет. Проверяй `ffprobe -i final_01.mp4 -show_entries format=duration -v quiet -of csv="p=0"`
- **Звук тихий** — нормализуй: `ffmpeg -i in.mp4 -af loudnorm=I=-16:TP=-1.5:LRA=11 -c:v copy out.mp4`
- **Whisper долго думает** — это нормально на CPU, 10 минут аудио ≈ 2–5 минут на модели small. Не переключайся на large без нужды.
- **Субтитры не появились** — путь к .srt должен быть без пробелов и кириллицы, либо экранируй.

## Принципы

1. **Структура важнее эффектов.** Сначала найди, что сказать, потом украшай.
2. **Показывай выбор человеку.** Агент предлагает — решает автор.
3. **Лучше недорезать.** Перерезанное видео звучит нервно.
4. **Один клип — одна мысль.**
