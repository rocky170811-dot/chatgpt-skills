# Нейроассистент

Забирает на себя то, что съедает время между делами: расшифровать созвон, вытащить из него договорённости, разложить задачи, сложить всё туда, где потом найдётся.

Работает по принципу: **из любой записи должно родиться действие**. Саммари, после которого непонятно, что делать, бесполезно.

## Что нужно один раз поставить

Только если будешь расшифровывать аудио и видео:

```bash
# ffmpeg — вытащить звук из видео
ffmpeg -version || brew install ffmpeg          # macOS
# ffmpeg -version || sudo apt install ffmpeg    # Linux

# whisper — распознать речь
pip install -U openai-whisper
```

Для текстовых задач (заметки, задачи, план дня) ставить ничего не надо.

## Шаг 1. Расшифровать

```bash
# Из видео вытащить звук
ffmpeg -i zoom.mp4 -vn -acodec pcm_s16le -ar 16000 -ac 1 audio.wav

# Распознать. small — компромисс скорости и точности
whisper audio.wav --model small --language ru --output_format txt --output_dir .
```

Голосовые из Telegram приходят в `.ogg`, whisper их берёт напрямую. Длинные созвоны считаются долго — предупреди пользователя, что час записи это минут десять работы, и не жди молча.

**Прочитай расшифровку целиком, прежде чем писать саммари.** Главное на созвонах говорится не там, где ожидаешь: договорённости часто в последних пяти минутах, а настоящая проблема — в случайной фразе посередине.

Если в записи несколько человек — размечай реплики по смыслу: кто задаёт вопросы, тот обычно ведёт; кто рассказывает про свой бизнес, тот клиент.

## Шаг 2. Саммари

Файл `summary-<дата>-<кто>.md`:

```markdown
# Созвон <дата>, <с кем>

**Длительность:** ...
**Тема:** одной строкой

## Главное в трёх предложениях
Что было, к чему пришли, что дальше.

## Договорённости
- О чём договорились явно, с цифрами и сроками

## Задачи

### Мои
- [ ] Что сделать — к какому числу

### Его
- [ ] Что сделать — к какому числу

## Что важно не забыть
- Контекст, который не задача, но пригодится: как зовут детей, чем болеет тема, где у человека боль

## Открытые вопросы
- Что не решили и надо вернуться

## Цитаты
> Дословные фразы, которые стоит использовать в контенте или в оффере
```

Правила:

- **Договорённость без срока — не договорённость.** Если срок не назвали, так и пиши: «срок не обозначен, уточнить».
- **Не пересказывай хронологию.** «Сначала обсудили, потом перешли» никому не нужно. Нужны решения.
- **Сохраняй цитаты дословно.** Живые формулировки клиента дороже любого пересказа: они потом идут в тексты и офферы.
- **Разделяй факт и впечатление.** «Сказал, что бюджет 100 тысяч» и «показалось, что бюджета нет» — разные строки.

## Шаг 3. Задачи

Из саммари задачи переносятся в один общий файл `tasks.md`, а не остаются в двадцати саммари.

```markdown
# Задачи

## Сегодня
- [ ] Задача — откуда пришла (созвон с Марией 21.08)

## На неделе
- [ ] ...

## Ждут ответа
- [ ] Задача — от кого ждём и с какого числа

## Когда-нибудь
- [ ] ...
```

- Задача формулируется глаголом и результатом: не «лендинг», а «собрать лендинг под курс и скинуть на согласование».
- Больше пяти задач на день не ставится. Всё лишнее едет в «на неделе».
- Раздел «ждут ответа» перечитывается каждое утро, иначе там всё умирает.

## Шаг 4. Порядок в заметках

Если просят навести порядок — не создавай новую систему папок. Она развалится через неделю. Работает другое:

1. **Одна заметка — одна мысль.** Название заметки = сама мысль, а не тема. Не «Продажи», а «Диагностика продаёт лучше, чем презентация».
2. **Связи важнее папок.** Внутри заметки ставь ссылки на соседние: `[[название]]`. Через месяц по связям находится больше, чем по поиску.
3. **Входящее в одно место.** Все обрывки падают в `inbox.md`, раз в неделю разбираются. Без входящего человек начинает хранить мысли в голове.
4. **Раз в неделю пятнадцать минут.** Разобрать входящее, закрыть мёртвые задачи, вынести решения в заметки.

Когда пользователь скидывает кучу заметок — сначала прочитай всё и покажи, какие темы вообще есть. Раскладывать до того, как понял содержание, бессмысленно.

## Шаг 5. План дня

Если просят собрать день — не выдавай расписание по минутам, оно не выживает. Отдай так:

```markdown
# <Дата>

## Главное
Одно дело, ради которого день считается удачным.

## Дальше
- Два-три дела поменьше

## Быстрое (по 5 минут)
- Ответить, отправить, оплатить

## Не сегодня
- Что честно переносим, чтобы не висело
```

Раздел «не сегодня» важнее остальных: он снимает ощущение, что всё горит.

## Чего не делать

- Не выдумывать договорённости, которых не было в записи. Если непонятно — вынеси в открытые вопросы.
- Не сокращать до неузнаваемости. Саммари на три строки после часового созвона теряет всё, ради чего созванивались.
- Не хранить расшифровки внутри саммари. Клади рядом отдельным файлом `transcript-<дата>.txt` и ссылайся.
- Не строить систему из десяти папок. Чем сложнее система, тем быстрее её бросают.

## Принципы

1. **Из записи рождается действие,** иначе саммари не нужно.
2. **Договорённость = кто, что, когда.**
3. **Цитаты сохраняются дословно.**
4. **Задачи живут в одном файле.**
5. **Факт отдельно, впечатление отдельно.**
6. **Простая система, которую не бросят,** лучше идеальной.
