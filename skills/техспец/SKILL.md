# Нейротехспец

Собирает Telegram-бота, который реально запускается и работает. Не схемы и не n8n — живой Python-файл, который можно поднять за 15 минут.

## Что бот умеет из коробки

- Отвечает на `/start` приветствием и кнопками
- Выдаёт лид-магнит (файл или ссылку) — можно за подписку на канал
- Принимает заявки и складывает в CSV
- Отвечает через ИИ (опционально, если есть ключ Anthropic)

## Порядок работы

### Шаг 1. Спроси, что за бот

Не пиши код, пока не понял:

1. **Задача бота** — выдать файл / собрать заявки / отвечать на вопросы / всё сразу?
2. **Есть токен?** Если нет — веди по инструкции ниже.
3. **Нужна ли проверка подписки** на канал перед выдачей?

### Шаг 2. Получить токен

Скажи пользователю сделать это руками:

1. Открыть [@BotFather](https://t.me/BotFather) в Telegram
2. Отправить `/newbot`
3. Ввести имя бота (любое, например «Мой помощник»)
4. Ввести username — обязательно заканчивается на `bot` (например `moy_helper_bot`)
5. BotFather пришлёт токен вида `7123456789:AAH...` — скопировать

**Токен нельзя коммитить и вставлять в код.** Только в `.env`.

### Шаг 3. Поставить зависимости

```bash
pip install -U python-telegram-bot python-dotenv
```

### Шаг 4. Создать проект

Создай папку и три файла: `bot.py`, `.env`, `.gitignore`.

Готовый шаблон бота лежит в репозитории: `templates/bot_template.py`. Скопируй его и подгони под задачу.

`.env`:
```
BOT_TOKEN=сюда_токен_от_BotFather
CHANNEL=@имя_канала        # необязательно — для проверки подписки
ANTHROPIC_API_KEY=         # необязательно — для ИИ-ответов
```

`.gitignore`:
```
.env
*.csv
__pycache__/
```

### Шаг 5. Запустить

```bash
python bot.py
```

В терминале появится `Бот запущен`. Напиши боту `/start` в Telegram — он ответит.

Пока терминал открыт — бот живой. Закрыл терминал — бот умер. Это нормально для теста.

### Шаг 6. Чтобы бот работал круглосуточно

Объясни варианты честно, без магии:

| Вариант | Кому | Как |
|---------|------|-----|
| Свой компьютер | Только потестить | Просто не закрывать терминал |
| VPS (5$/мес) | Боевой бот | Загрузить файл, запустить через `screen` или `systemd` |
| Railway / Render | Не хочет сервер | Подключить репозиторий, задать переменные окружения |

Самое простое для новичка — VPS + `screen`:
```bash
screen -S bot          # создать сессию
python bot.py          # запустить
# Ctrl+A, потом D — выйти, бот продолжит работать
screen -r bot          # вернуться к нему
```

## Проверка подписки на канал

Чтобы бот проверял подписку, его нужно **сделать администратором канала** — иначе Telegram не даст ему читать список участников. Скажи это пользователю прямо, на этом спотыкаются все.

Код проверки — в шаблоне, функция `is_subscribed`.

## Подключение ИИ

Если пользователь хочет умные ответы:

1. Ключ берётся на console.anthropic.com — это платно, предупреди
2. `pip install anthropic`
3. Раскомментировать блок ИИ в шаблоне
4. Задать боту роль в `SYSTEM_PROMPT` — кто он и как отвечает

Держи ответы короткими: в Telegram лимит 4096 символов, и длинные простыни никто не читает.

## Частые грабли

- **`Unauthorized`** — токен неверный или с пробелом. Проверь `.env`.
- **Бот молчит** — запущено две копии одного бота. Telegram отдаёт апдейты только одной. Проверь точный PID и останови только нужный экземпляр через управление службой или адресный сигнал.
- **`Chat not found` при проверке подписки** — бот не админ канала, либо username канала без `@`
- **Кнопки не нажимаются** — забыт `CallbackQueryHandler` или не вызван `query.answer()`
- **Кириллица в CSV кракозябрами** — открывать через импорт с UTF-8, либо писать с `encoding='utf-8-sig'`

## Принципы

1. **Сначала запусти пустышку**, потом наворачивай. Работающий `/start` важнее красивой архитектуры.
2. **Токен только в `.env`.** Никогда в код, никогда в git.
3. **Проверяй на себе** перед раздачей людям.
4. **Не обещай круглосуточность** без сервера — объясни честно.
